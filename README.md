# FixMyStreet — Website starter

A responsive, design-first landing page for the FixMyStreet civic issue reporting platform. Initial pilot concept: Jalandhar, Punjab.

## Stack
- Next.js 15 / React 19 / TypeScript
- Custom responsive CSS
- Lucide icons

## Run locally

1. Install Node.js 20.9 or later.
2. Open this folder in VS Code.
3. In the terminal run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Current scope
This is the frontend landing-page prototype. The issue cards and map are illustrative, the complaint tracker explains that backend integration is pending, and login/report CTAs are visual navigation placeholders. No real complaints are submitted or sent to municipal authorities yet.
